## Setup Instructions
# 1. Make sure you have Flutter installed (version 3.9.2 or higher)
# 2. Run 'flutter pub get' to install all dependencies
# 3. For Firebase setup, run 'flutterfire configure' to generate firebase_options.dart
# 4. Make sure you have the google-services.json file in android/app/ directory

## Additional Setup Notes
# - The firebase_options.dart file needs to be properly configured with your Firebase project credentials
# - For iOS builds, you'll also need the GoogleService-Info.plist file
# - Make sure to enable required Firebase services (Authentication, Firestore) in the Firebase Console
