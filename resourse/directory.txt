# Project Directory Structure & File Analysis - MiniMart

## � Root Level
| File/Directory | Purpose |
| :--- | :--- |
| **`lib/`** | Contains all the Dart code for the application. |
| **`assets/`** | Stores static resources (Images, Icons). |
| **`test/`** | Contains Unit and Widget tests. |
| **`resourse/`** | Project documentation, planning files, and logs. |
| **`pubspec.yaml`** | Manages dependencies, assets, and app versioning. |
| **`firebase_options.dart`** | Auto-generated configuration for connecting to Firebase projects. |
| **`firestore.rules`** | Security rules deployed to Cloud Firestore. |
| **`analysis_options.yaml`** | Linter rules for Dart code quality. |

---

## 📂 lib (Application Logic)

### 🔐 lib/auth (Authentication Module)
| File | Description |
| :--- | :--- |
| **`login_screen.dart`** | UI for user sign-in. Handles email/password inputs and error states. |
| **`signup_screen.dart`** | UI for registration. Triggers finding account creation and email verification. |
| **`forgot_password_screen.dart`** | UI to trigger password reset emails via Firebase. |

### 🧩 lib/providers (State Management - ViewModel)
| File | Description |
| :--- | :--- |
| **`auth_provider.dart`** | Manages User Session (`FirebaseAuth`), Sign In/Up logic, and User Profile fetching. |
| **`products_provider.dart`** | Fetches products from Firestore, handles Admin CRUD (Add/Delete), and Search/Sort logic. |
| **`cart_provider.dart`** | Manages Cart state (Add/Remove items), calculates Totals, and handles Coupon validation. |
| **`orders_provider.dart`** | Handles Order placement (writing to Firestore) and fetching Order History. |
| **`wishlist_provider.dart`** | Manages the list of favorite products (`users/{uid}/wishlist`). |
| **`theme_provider.dart`** | Manages the global Light/Dark theme state using `SharedPreferences`. |

### 📱 lib/screens (UI Pages)
| File | Description |
| :--- | :--- |
| **`main_screen.dart`** | The "Home" wrapper. Usually handles the Bottom Navigation logic (if separate). |
| **`shop_page.dart`** | The main Dashboard. Displays Product Grid, Search Bar, and Categories. |
| **`product_details_page.dart`** | Single product view. Shows large image, description, and "Add to Cart" FAB. |
| **`cart_page.dart`** | Displays added items. Swipe-to-delete. Proceed to checkout. |
| **`checkout_page.dart`** | Form for Shipping Info. Selector for Payment Method. "Place Order" button. |
| **`order_confirmation_page.dart`** | Success screen shown after placing an order. |
| **`orders_page.dart`** | List of past orders. Expandable tiles show order contents. |
| **`wishlist_page.dart`** | Grid view of "Hearted" items. |
| **`profile_page.dart`** | User Settings. Dark Mode toggle. Edit Profile. Link to **Admin Panel**. |
| **`admin_page.dart`** | (Hidden) Interface to Add or Delete products from the global catalog. |
| **`category_products_page.dart`** | Filtered view showing products of a specific category. |

### 🧱 lib/widgets (Reusable Components)
| File | Description |
| :--- | :--- |
| **`product_grid_item.dart`** | The individual card in the grid (Image + Title + Price + Heart Icon). |

| **`cart_item_widget.dart`** | The list tile used in Cart Page with Qty +/- controls. |
| **`order_item_widget.dart`** | The expandable tile used in Orders Page. |
| **`app_drawer.dart`** | Side menu (Hamburger) for navigation. |
| **`custom_bottom_nav_bar.dart`** | Bottom navigation bar widget. |
| **`app_bar.dart`** | Custom App Bar widget (if extracted). |
| **`snackbar.dart`** | Helper for showing standardized error/success messages. |
| **`splash_screen.dart`** | The initial loading screen shown while Firebase initializes. |
| **`location_select.dart`** | (Optional) Widget for picking location (if implemented). |

### � lib/models (Data Transfers)
| File | Description |
| :--- | :--- |
| **`product.dart`** | Defines `id`, `title`, `price`, `description`, `imageUrl`, `category`. |
| **`coupon.dart`** | Defines `code`, `discountValue`, `discountType`, `expiryDate`. |


### ⚙️ lib/services (Background Logic)
| File | Description |
| :--- | :--- |

| **`seeder_service.dart`** | Auto-injects demo data (Coupons/Products) if the database is empty. |
| **`image_cache_service.dart`** | Utilities for handling image caching (if implemented). |
