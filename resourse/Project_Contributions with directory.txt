# Project Contributions Report & Handover

## Overview
This document details the division of work between team members for the MiniMart project, including the specific files and directories associated with each task.

## 👤 Member 1 Contributions (Foundational & Core)
**Focus:** Project Setup, Core Architecture, Authentication, and Basic E-commerce Flow.

### 1. Core Infrastructure
- **Project Setup:** Initial Flutter app creation, Firebase project configuration.
  - `lib/main.dart` (Base setup)
  - `lib/firebase_options.dart`
- **State Management:** Implemented the `Provider` architecture.
  - `lib/providers/auth_provider.dart`
  - `lib/providers/products_provider.dart` (Base implementation)
  - `lib/providers/cart_provider.dart` (Base implementation)
  - `lib/providers/orders_provider.dart`

### 2. Authentication & User Management
- **Firebase Auth:** Sign Up, Sign In, Profile.
  - `lib/auth/login_screen.dart`
  - `lib/auth/signup_screen.dart`
  - `lib/auth/forgot_password_screen.dart`
  - `lib/screens/profile_page.dart` (Base UI)

### 3. Product & Shopping Core
- **Product Catalog & Details:**
  - `lib/screens/shop_page.dart` (Product Grid)
  - `lib/screens/product_details_page.dart` (Base details)
  - `lib/widgets/product_grid_item.dart`
  - `lib/models/product.dart`
- **Cart System & Orders:**
  - `lib/screens/cart_page.dart`
  - `lib/screens/checkout_page.dart` (Address form & base logic)
  - `lib/screens/orders_page.dart`
  - `lib/screens/order_confirmation_page.dart`

### 4. UI/UX Essentials
