# Project Contributions Report & Handover

## Overview
This document details the division of work between team members for the MiniMart project.

## 👤 Member 1 Contributions (Foundational & Core)
**Focus:** Project Setup, Core Architecture, Authentication, and Basic E-commerce Flow.

### 1. Core Infrastructure
- **Project Setup:** Initial Flutter app creation, Firebase project configuration (Android/iOS).
- **State Management:** Implemented the `Provider` architecture (`AuthProvider`, `ProductsProvider`, `CartProvider`, `OrdersProvider`).
- **Database:** Designed Firestore schema for Users, Products, and Orders.

### 2. Authentication & User Management
- **Firebase Auth:** Implemented Sign Up, Sign In, and Sign Out functionalities.
- **Security:** Added Email Verification workflow and securely stored user data.
- **Profile:** Basic profile view and editing (Name/Phone).

### 3. Product & Shopping Core
- **Product Catalog:** Fetched and displayed products from Firestore in `ShopPage`.
- **Product Details:** Created detailed view with images and description.
- **Cart System:**
  - Full CRUD operations (Add, Remove, update Quantity).
  - Real-time subtotal calculation.
- **Checkout & Orders:**
  - Built `CheckoutPage` (Form validation, Address input).
  - Implemented Order placement logic.
  - created `OrdersPage` to view order history.

### 4. UI/UX Essentials
- **Navigation:** App Drawer and Custom Bottom Navigation Bar.
- **Splash Screen:** Animated starting screen.
- **Visuals:** Base theme setup, Pull-to-refresh, and Toast/Snackbar messages.
